# Visual review

Chromium headless screenshots at 1440×1000 and 390×844 were opened and inspected. Portfolio, transaction assistant, ten-payee graph, common-director graph, circular-flow graph, borrower, evidence reassessment, case closure, technology view, coverage/targets and mobile portfolio were captured.

Reviewed: UCO blue/yellow branding; readable page hierarchy; amount formatting; source links; graph edge labels and source list; table scrolling; assistant drawer; reviewer state; service-status truthfulness; mobile navigation and absence of page-wide overflow. The two-counterparty graph layout was adjusted to a triangle so a relationship line no longer crossed the borrower node. Screenshot captures scroll to the top and dismiss transient notifications.

Keyboard checks covered source-dialog Escape, focus return, visible focus styles and tab navigation. Evidence modal and assistant drawer include focus traps. This is not a full WCAG audit, screen-reader audit or Safari/Firefox compatibility certification. The actual end-to-end browser workflow report is browser-results.json.
